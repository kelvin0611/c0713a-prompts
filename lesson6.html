PART 1

五個虛擬實驗

對應初中科學科課程。每個先複製大 prompt，再用 chip 一路改。

ALL一次過生成晒五個實驗 🎪

唔想逐個做？呢個 prompt 會生成一個網頁，入面有五個實驗，上面有目錄可以切換
請用 Canvas 做一個「可愛科學遊樂場」，一個網頁入面包含五個互動科學實驗，
全部用 HTML + CSS + JavaScript，唔好用外部 library。

【版面】
- 頂部有 5 個圓潤可愛嘅大按鈕／標籤，切換以下五個實驗（唔使重新載入頁面）
- 每個實驗都係獨立一個區塊，切換時有柔順嘅淡入動畫

【實驗一：聲音 🔊】
- 可愛音叉角色，振動時出聲 + 水面波紋
- 頻率滑桿 20–20000 Hz，即時畫出聲波波形（頻率越高波形越密）
- 波形可切換：正弦波／方波／三角波／鋸齒波（同一頻率下音色唔同、音高一樣）
- 介質切換：固體 / 液體 / 空氣 / 真空（真空冇聲）
- 顯示「Hz 係頻率嘅單位」同「人類聽到 20–20000 Hz」

【實驗二：光合作用 🌱】
- 可愛盆栽（有表情），太陽可拖動或滑桿調光暗
- CO₂ 同 H₂O 小角色飄入，氧氣泡泡由葉飄出（光越強泡泡越多）
- 顯示文字反應式同化學反應式
- 四項條件開關（光、葉綠素、二氧化碳、水），關掉任何一項就停止

【實驗三：光的反射 · 折射 · 全內反射 🔦】
- 雷射筆射光線，入射角可調
- 同時畫出入射線、反射線、折射線（三種顏色）＋ 標示角度
- 介質可揀：水 / 玻璃 / 鑽石（臨界角 48.8° / 41.8° / 24.4°）
- 入射角超過臨界角 → 出「全內反射！」特效，折射線消失
- 顯示斯涅爾定律 n₁sinθ₁ = n₂sinθ₂ 並代入數字

【實驗四：眼睛與透鏡成像 👁️】
- 可愛眼睛剖面圖（角膜、瞳孔、晶狀體、視網膜、視神經）
- 可拖動物件 + 光線圖顯示聚焦過程
- 切換正常眼 / 近視眼 / 遠視眼；近視遠視時畫面用 CSS blur 變模糊
- 「戴眼鏡」按鈕：加正確鏡片後畫面變清（近視用凹透鏡、遠視用凸透鏡）

【實驗五：焰色反應 🔥】
- 可愛本生燈，揀元素（鈉鉀鈣銅鍶鋇鋰）火焰變真色
- 鈉金黃、鉀淡紫、鈣磚紅、銅藍綠、鍶深紅、鋇黃綠、鋰洋紅
- 加一個小測驗：隨機出焰色，估係咩元素

【風格】（重點）
- 粉彩色：粉紅 #FFB3C6、粉藍 #A8DADC、薄荷綠 #B8E6D5、淡黃 #FFE9A8
- 所有元素圓潤：大圓角、粗邊框（3px）、柔和陰影
- 動畫柔順（CSS transition），唔好突然跳
- 少量 emoji：🔊 🌱 🔦 👁️ 🔥 ✨
- 整體感覺：似小朋友嘅玩具 app，唔係教科書

【額外】
- 手機同電腦都要睇得靚（responsive）
- 每個實驗都要有一句「呢個實驗學緊咩」（用中學生聽得明嘅講法）
👇 生成完之後，可以用呢啲 chip 繼續改：
應該見到：一個網頁，頂部五個掣，撳落去切換五個實驗。
⚠️ 如果一次生成太多，有啲實驗做得唔靚 → 冇問題，逐個叫佢改善就得（例如「實驗三嘅光線唔夠清楚，請重做」）。

1聲音 🔊

課程：單元十 10.3 聽覺 —— 聲音由振動產生、藉介質傳送、用 Hz 量度頻率
請用 Canvas 做一個「可愛聲音實驗室」互動網頁，全部用 HTML + CSS + JavaScript，唔好用外部 library。

要有：
1. 一個可愛嘅音叉角色（有眼睛），撳佢會振動並出聲
2. 振動嘅音叉輕觸水面會產生一圈圈波紋（動畫）
3. 用 canvas 即時畫出聲波波形 —— 頻率越高，波形越密
   ⚠️ 波形要有得揀：正弦波（圓滑）／方波／三角波／鋸齒波
4. 一個圓潤嘅大滑桿調校頻率，由 20 Hz 到 20000 Hz
5. 顯示頻率數值，並講明「Hz 係頻率嘅單位」；同時顯示「人類聽到嘅範圍約 20-20000 Hz」，
   當滑到人耳聽唔到嘅範圍，出提示「呢個頻率人耳聽唔到（超聲波／次聲波）」
6. 場景切換示範「介質」：固體 / 液體 / 空氣 / 真空 —— 真空嗰陣聲音完全傳唔到，
   出「真空中冇聲！」並顯示一個呆咗嘅表情
7. 一個「樂器」小區：鋼琴、鼓、結他，撳落去示範唔同樂器點樣產生聲音
8. 一個「波形實驗室」：同一頻率下可以切換四種波形（正弦／方波／三角／鋸齒），
   波形圖即時變形，聲音嘅音色亦跟住變 —— 但音高一樣。
   要出一句解釋：「音高由頻率決定，音色由波形決定」

風格：粉彩色（粉紅、粉藍、薄荷綠、淡黃）、粗邊框、圓角、柔和陰影、emoji（🔊🎵✨）、動畫柔順。
👇 撳一下就複製，貼落 Gemini 繼續改：
應該見到：拖頻率滑桿 → 波形疏密變、聲音高低變；切去真空 → 冇聲。
自己加嘢：諗到咩都可以打落 Gemini，唔一定要用 chip。

2光合作用 🌱

課程：單元七 —— 條件（光／葉綠素／二氧化碳／水）、產物（葡萄糖→澱粉 ＋ 氧）
請用 Canvas 做一個「可愛植物光合作用」互動模擬網頁，全部用 HTML + CSS + JavaScript，唔好用外部 library。

要有：
1. 一棵可愛盆栽（用 CSS 砌，有眼睛同微笑），會微微擺動
2. 一個太陽可以拖動，或用滑桿調光暗（由夜晚到猛烈太陽）
3. 小角色分子飄入去：二氧化碳 CO₂（灰色）同水 H₂O（藍色），要有表情
4. 完整顯示文字反應式同化學反應式：
   二氧化碳 ＋ 水 —（光和葉綠素）→ 葡萄糖 ＋ 氧
   6CO₂ ＋ 6H₂O —（光和葉綠素）→ C₆H₁₂O₆ ＋ 6O₂
5. 氧氣泡泡由葉飄出，光越強 → 泡泡越多越快
6. 一個「條件檢查表」，四項（光、葉綠素、二氧化碳、水）可以撳掣開關；
   任何一項關掉 → 光合作用停止，植物出「做唔到光合作用…」表情
7. 一個「澱粉測試」按鈕：示範用碘液檢測葉有冇澱粉，有澱粉會變藍黑色
8. 計數器：「製造咗 N 個氧氣泡」

風格：粉彩色、圓潤、粗邊框、柔和陰影、emoji（🌱☀️💧🫧🧪）、動畫柔順。
👇 撳一下就複製，貼落 Gemini 繼續改：
應該見到：關掉「光」或「二氧化碳」→ 泡泡停；拖光暗 → 泡泡即時變。
考自己：點解夜晚放嘅氣體唔同？

3光的反射 · 折射 · 全內反射 🔦

課程：單元十四 14.2–14.4 —— 光線圖、反射定律、折射、全內反射的條件
請用 Canvas 做一個「可愛光線歷險記」互動網頁，全部用 HTML + CSS + JavaScript，唔好用外部 library。

要有：
1. 一個可愛嘅光線角色（有眼睛嘅小圓點，拖住發光尾巴）
2. 一塊半透明介質（水 / 玻璃 / 鑽石），可以揀
3. 一支雷射筆射光線，入射角用滑桿或拖動調校
4. 同時畫出三條線（唔同顏色）：入射線、反射線、折射線
5. 標示入射角、反射角、折射角（弧形箭頭 ＋ 度數）
6. 顯示斯涅爾定律 n₁ sin θ₁ = n₂ sin θ₂，並代入實際數字計算
7. 當入射角超過臨界角 → 出「全內反射！」特效（折射線消失、反射線變粗、加星星），
   並用一句話講清楚全內反射嘅條件：光由光密介質射向光疏介質、入射角大於臨界角
8. 顯示每個介質嘅臨界角（水 48.8°、玻璃 41.8°、鑽石 24.4°）
9. 一個「日常例子」區：光纖、內窺鏡、鑽石閃爍、水中筷子看似折曲

風格：粉彩色、圓潤、光線要有表情、星星閃、動畫柔順、emoji（🔦✨💎）。
👇 撳一下就複製，貼落 Gemini 繼續改：
應該見到：由水轉鑽石 → 臨界角變細；入射角過臨界角 → 折射線消失。
課程連結：呢個對應課本嘅「半圓玻璃塊 ＋ 光線箱」實驗。

4眼睛與透鏡成像 👁️

課程：單元十 10.2 視覺 ＋ 單元十四 14.5／14.6 —— 晶狀體、視網膜、凸透鏡會聚、凹透鏡發散
請用 Canvas 做一個「可愛眼睛睇嘢」互動網頁，全部用 HTML + CSS + JavaScript，唔好用外部 library。

要有：
1. 一對可愛嘅眼睛（有眼睫毛、瞳孔、會眨眼）
2. 眼睛剖面圖：標示角膜、瞳孔、晶狀體、視網膜、視神經（用可愛風標籤）
3. 一個可以拖動嘅物件（例如一朵花 🌸），放喺眼睛前面唔同距離
4. 光線圖：光線由物件頂部射出，經過晶狀體折射，會聚到視網膜
5. 滑桿調整：物件距離、晶狀體焦距（模擬眼睛調節）
6. 即時顯示成像性質：倒立、放大／縮小、實像
7. 切換三種情況：
   - 正常眼 → 焦點啱啱喺視網膜
   - 近視眼（眼球太長）→ 焦點喺視網膜前面，畫面用 CSS blur 變模糊，顯示要用凹透鏡矯正
   - 遠視眼（眼球太短）→ 焦點喺視網膜後面，同樣模糊，顯示要用凸透鏡矯正
8. 一個「戴眼鏡」按鈕：撳落去加上正確鏡片，畫面即時變清
9. 一個示範：看近處物件同遠處物件時，晶狀體嘅形狀有咩唔同（會變厚／變薄）

風格：粉彩色、圓潤、可愛有表情、emoji（👁️🌸🔍👓）、動畫柔順。
👇 撳一下就複製，貼落 Gemini 繼續改：
應該見到：拖物件 → 焦點位置郁；切近視 → 焦點喺前面、畫面模糊；戴眼鏡 → 變清。
考自己：點解近視要戴凹透鏡、遠視要戴凸透鏡？

5焰色反應 🔥 （延伸）

⚠️ 呢個唔喺初中科學科課程（屬高中化學），當作趣味延伸實驗
請用 Canvas 做一個「可愛化學實驗室：焰色測試」互動網頁，全部用 HTML + CSS + JavaScript，唔好用外部 library。

要有：
1. 一個可愛嘅本生燈（有眼睛），火焰會微微跳動
2. 一排可以揀嘅元素按鈕：鈉 Na、鉀 K、鈣 Ca、銅 Cu、鍶 Sr、鋇 Ba、鋰 Li
3. 撳一個元素 → 一條鉑絲沾咗嗰個元素放入火焰 → 火焰變成該元素真實嘅焰色：
   鈉 Na → 金黃色｜鉀 K → 淡紫色｜鈣 Ca → 磚紅色｜銅 Cu → 藍綠色
   鍶 Sr → 深紅色｜鋇 Ba → 黃綠色｜鋰 Li → 洋紅色
4. 火焰顏色要平滑過渡，並有火焰跳動動畫
5. 顯示元素名、符號、同焰色嘅中文名稱
6. 一個「小測驗」模式：隨機出一個焰色，叫學生估係咩元素，答對有星星
7. 一個「冷知識」區：焰色測試用嚟鑑定金屬離子，煙花嘅顏色就係用呢個原理

風格：粉彩色底、火焰用真色、圓潤、粗邊框、emoji（🔥🧪✨）、動畫柔順。
👇 撳一下就複製，貼落 Gemini 繼續改：
應該見到：撳唔同元素，火焰即時轉色。
⚠️ 記住：呢個只係模擬。真實做要老師示範 ＋ 安全措施。
