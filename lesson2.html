PART 1

個人化任務

5 個任務，做完你嘅 App 就唔再同隔籬位一樣。跟住做，每個做完都撳 Keep All ＋ 重新整理。

1換主題色

目標：由黑色紅色變成你自己揀嘅配色
請幫我改 @index.html 嘅主題顏色（或者 @style.css，如果你有呢個檔）。

而家嘅顏色係寫喺 :root 裡面嘅 CSS 變數：
  --bg（背景）、--card（卡片底）、--accent（按鈕主色）、--fg（文字色）

我想改成呢幾隻色：
  背景（--bg） = （填你想要嘅顏色，例如「深藍色」）
  卡片（--card） = （例如「淺一級嘅深藍」）
  按鈕（--accent） = （例如「橙黃色」）

要求：
- 只改 :root 呢幾個變數嘅值，唔准喺其他地方寫死顏色（唔准出現 #xxxxxx 直接寫喺 selector）
- 所有顏色一律要經 var(--xxx) 取，咁以後改一隻色就全部跟住變
- 文字要睇得清（對比要夠），唔好淺色字配淺色底
- 其他版面、功能一律唔好郁
應該見到：重新整理之後，背景、卡片、按鈕全部換成你揀嘅色，但排版一模一樣。
點知佢有冇寫死顏色？喺 Cursor 搜尋 #，如果你揀嘅色只出現喺 :root 一段， 咁就啱。想再玩 → 再叫佢「換第 2 套色，一樣只改 :root」。
⚠️ 唔好淨係叫「整靚啲」。要講明改邊幾個變數、改成咩色，AI 才會做你想嘅嘢。

2改 App 名 ＋ emoji

目標：個標題寫住你嘅名，仲有你自己揀嘅 emoji
請改 @index.html 嘅標題部分。

1. 將 <h1> 嘅文字改成：（寫你嘅名）嘅交通 App
2. 標題前面加一個 emoji：（填你想要嘅 emoji，例如 🚌、🚇、🏠、⚡）
3. 順手改埋 <title> 標籤嘅文字（即係瀏覽器分頁上面顯示嘅字），同 h1 一致
4. 副標題／說明文字如果仲寫住「香港交通到站 App」，都改埋做你嘅版本

嚴格要求：
- 只准改標題相關嘅文字，其他一律唔好郁
- 唔好改 CSS、唔好改 JavaScript、唔好改任何 id 同 class 名
- 唔好加任何新嘅 <style> 或 <script>
應該見到：個 App 頂頭變成「🚌 阿明嘅交通 App」，瀏覽器分頁名都跟住變。
想更型？再叫佢「幫我加一句 tagline 喺標題下面，語氣似中學生，一串字內」。

3加「我屋企」掣

目標：撳一下，就知你屋企附近有咩巴士站
請幫我加一個新功能：「搵我附近嘅巴士站」。

做法：
1. 喺 @index.html 加一個按鈕，文字係「📍 我附近嘅站」，id="btn-nearby"
2. 撳咗之後用 navigator.geolocation.getCurrentPosition() 攞用戶位置
3. 攞到之後，去呢個網址攞一次全港巴士站資料：
   https://data.etabus.gov.hk/v1/transport/kmb/stop/
   回應格式係 { data: [ { stop, name_tc, lat, long }, ... ] }
   ⚠️ 呢個回應裡面每個站都已經有 lat 同 long，所以只可以 fetch 一次，
   絕對唔可以逐個站再 fetch 一次（792 個站逐個 fetch 會慢到死）
4. 用 Haversine 公式計每個站同你嘅距離，排序，取最近嘅 5 個
5. 結果放入 id="nearby-list"，每個顯示：「站名　約 120 米」
6. 距離用米顯示，唔好顯示一大堆小數位

⚠️ 最重要嘅一點：如果用戶拒絕分享位置（或者瀏覽器唔支援），
唔准出紅色 error、唔准令畫面爛。
要喺 id="nearby-list" 顯示一句友善嘅中文提示，例如：
「分享唔到位置，唔緊要 —— 你照樣可以喺上面撳路線號碼㨂站 🙂」
所有 fetch 都要用 try / catch 包住，失敗就出友善訊息。
應該見到：撳個掣 → 瀏覽器問你俾唔俾位置 → 俾就出最近 5 個站同距離。
一定要試埋「拒絕」：重新整理，撳個掣，然後揀 「不允許」 —— 應該出一句友善中文，唔係紅色 error，個 app 亦都仲用得。
⚠️ 呢個任務嘅重點唔係「搵到最近嘅站」，而係用戶唔俾權限嗰陣，你嘅程式唔會死。

4收藏路線（記得住）

目標：收藏咗嘅路線，關咗個 app 再開都仲在
請幫我加「收藏路線」功能。

1. 每條路線掣旁邊加一粒細細嘅星 ⭐（或者 ❤️），撳佢就收藏／取消收藏
2. 收藏咗嘅路線，掣上面要有個標記（例如變色或者加實心星）
3. 收藏清單要顯示喺頁面頂，id="fav-list"，每條都可以撳（撳咗就同撳路線掣一樣）
4. 用 localStorage 儲存，key 一定係：my-fav-routes
   - 存嘅時候用 JSON.stringify()，讀嘅時候用 JSON.parse()
   - 頁面一載入就要即刻讀返出嚟，唔可以等到用戶撳嘢才讀
   - 讀嘅時候要 try / catch，如果 localStorage 壞咗或者係舊格式，
     就當佢係空清單，唔可以令成個 app 死

⚠️ 一定要真係寫入 localStorage。
唔准淨係存喺 JavaScript 變數或者記憶體 —— 咁樣重新整理之後就會唔見晒。

另外：其他 fetch 失敗嘅時候，唔好影響收藏清單顯示。
應該見到：收藏 1A、5C → 按 F5 重新整理 → 兩條線仲喺收藏清單。
自己驗證：按 F12 → Application → Local Storage → 應該見到一個叫 my-fav-routes 嘅 key，內容係 ["1A","5C"] 咁樣。
⚠️ 如果重新整理之後唔見咗，即係 AI 只係存喺記憶體。同佢講：「你用咗 localStorage 未？key 要係 my-fav-routes，重新整理之後一定要還在。」

5深色／淺色切換

目標：一粒掣切換日／夜模式，仲要記得你揀咗邊個
請幫我加「深色／淺色模式」切換。

1. 頁面右上角加一粒掣，id="btn-theme"，文字係「🌙 夜間」／「☀️ 日間」
2. 用 CSS 變數做，唔准寫死顏色：
   - 喺 :root 定義深色一組（--bg、--card、--card2、--fg、--muted、--border）
   - 再定義淺色一組
   - 整個網站所有顏色都要經 var(--xxx) 取
3. 切換嘅方法：喺 <html> 或 <body> 加／除一個 class（例如 .light），
   由 CSS 決定淺色嘅變數值。唔好用 JavaScript 逐個元素改 style。
4. 記住用戶揀咗邊個：用 localStorage，key 係 my-theme，
   值係 "dark" 或者 "light"
5. 頁面一載入就要即刻套用返上次揀嘅（唔可以閃一下先變）。
6. 預設（第一次開）用深色。

⚠️ 淺色模式都要睇得清：深色文字配淺色底，唔好留低白色字配白底。
所有 fetch 邏輯、收藏功能一律唔好郁。
應該見到：撳個掣 → 成個網站由深色變淺色，文字仲睇得清； 重新整理之後仍然係你上次揀嘅模式。
自己驗證：F12 → Application → Local Storage → 見到 my-theme = light 或 dark。
⚠️ 見到「閃一下」先變色，即係順序寫錯。同 AI 講：「主題套用要喺頁面渲染之前做，唔可以等 DOMContentLoaded。」
