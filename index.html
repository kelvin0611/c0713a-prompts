C0713A Prompt 卡

香港交通到站 App　·　嶺南衡怡紀念中學　·　按「複製」→ 貼落 Cursor
點用呢張卡？
  1. 開 Cursor，打開你嘅專案資料夾
  2. 右邊 Chat 面板，左下角揀 Agent 模式
  3. 撳下面任何一句嘅 「複製」
  4. 貼落 Cursor 對話框 → 按 Enter
  5. AI 寫完之後，一定要撳右上角 「Keep All」，再回瀏覽器 重新整理

1出路線掣

目標：畫面出到 792 個九巴路線號碼掣
請修改 @app.js 裡面嘅 loadRoutes() function：
- 用 fetch 攞 https://data.etabus.gov.hk/v1/transport/kmb/route/
- 回應係 { data: [ {route, bound, service_type}, ... ] }
- 只要 service_type 係 1，同一條路線去重
- 每條路線號碼做一個 button，放入 id="route-list"
- 失敗就喺 id="error" 顯示錯誤
應該見到：一大堆路線號碼掣（1、10、101、1A…）。 如果係空白，等 3 秒再撳「重新載入」。

2撳路線見站名

目標：撳 1A → 出 35 個真站名（中秀茂坪 → 尖沙咀碼頭）
請修改 @app.js 裡面嘅 loadStops() function：
- 撳路線掣之後，去 https://data.etabus.gov.hk/v1/transport/kmb/route-stop/{路線}/outbound/1
  （{路線} 換成學生㩒嘅號碼，例如 1A）
- 回應係 { data: [ {seq, stop}, ... ] }
- 另外去 https://data.etabus.gov.hk/v1/transport/kmb/stop/ 攞全港站名
- 整一個「站 ID → 站名」對照表，然後每個站做一個 button 放入 id="stop-list"
- 顯示格式：「1. 中秀茂坪」
應該見到：撳 1A 之後出 35 行站名，第一行係「1. 中秀茂坪」， 最後一行係「35. 尖沙咀碼頭」。

3幾多分鐘到站

目標：撳一個站 → 出「仲有幾分鐘」
請修改 @app.js 裡面嘅 showEta() function：
- 撳站之後，去 https://data.etabus.gov.hk/v1/transport/kmb/stop-eta/{站ID}
- 回應係 { data: [ {route, dest_tc, eta, eta_seq}, ... ] }
- eta 係一個時間字串，例如 "2026-09-18T16:30:00+08:00"，
  請計返仲有幾分鐘（同而家時間比較），如果冇 eta 就顯示「—」
- 站名寫入 id="eta-title"，班次放入 id="eta-list"
- 如果冇班次（data 係空陣列），顯示「呢個站暫時冇班次」
- 畫面唔好太長，只顯示頭 8 班
應該見到：例如「1A　去 尖沙咀碼頭　3 分鐘」。 收咗車嘅路線會顯示「—」—— 呢個係正常，唔係 bug。
⚠️ 如果全部都是「—」，可能係條線收咗車。試下撳第二條路線。

4加港鐵

目標：撳「中環站」→ 出港鐵下一班車
請修改 @app.js 裡面嘅 loadMtr() function：
- 去 https://rt.data.gov.hk/v1/transport/mtr/getSchedule.php?line=TWL&sta=CEN
- 回應係 { status: 1, data: { "TWL-CEN": { UP: [...], DOWN: [...] } } }
- 如果 status === 0，顯示「港鐵而家冇班次（可能收咗車）」
- 用 for...of 行 UP 同 DOWN 兩個方向，每個方向只顯示頭 3 班
- UP 顯示做「上行」、DOWN 顯示做「下行」
- 每個班次顯示：方向、去邊個站（dest）、仲有幾分鐘（ttnt 已經係分鐘）
- 放入 id="mtr-list"
應該見到：「上行　去 荃灣　2 分鐘」。 港鐵嘅 ttnt 本身就係「仲有幾分鐘」，唔使計。

5自動更新 + 唔怕斷線

目標：每 15 秒自己更新一次，斷線都唔會爛
請修改 @app.js 裡面嘅 startAutoRefresh() 同 refreshOnce() 兩個 function：
- startAutoRefresh(seconds)：
  - 先 clearInterval(timer) 清走舊嘅 timer（唔清就會愈跑愈快）
  - 然後 timer = setInterval(refreshOnce, seconds * 1000)
  - 將 id="btn-refresh" 嘅文字改成「自動刷新中…」同設 disabled = true
  - 最後即刻 await refreshOnce() 一次，唔使等 15 秒
- refreshOnce()：如果已經揀咗路線同站，就重新攞一次到站時間
  （即係再跑一次 loadStops 同 showEta 用到嘅邏輯）
- 全部 fetch 都要用 try / catch 包住：
  失敗就顯示「網絡有問題，等陣再試」，唔可以出紅色error或者令畫面爛咗
應該見到：撳「自動刷新」之後，個掣變灰、寫住「自動刷新中…」， 數字每 15 秒自己變一次。試下拔網線／熄 wifi —— 應該出友善訊息，唔係爛畫面。
⚠️ 呢個係最重要嘅一步：程式遇到錯誤唔可以死。真實世界一定會有網絡問題。
