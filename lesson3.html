Lesson 3 · 捉 AI 錯處

AI 會寫錯，你要捉到　·　嶺南衡怡紀念中學　·　按「複製」→ 貼落 Cursor
點用呢張卡？
  1. 開 Cursor，打開你 Lesson 1、2 嘅專案資料夾
  2. 右邊 Chat 面板，左下角揀 Agent 模式
  3. 撳下面任何一句嘅 「複製」
  4. 貼落 Cursor 對話框 → 按 Enter
  5. AI 寫完之後，一定要撳右上角 「Keep All」，再回瀏覽器 重新整理

今日唔一樣：唔係「AI 寫咩都得」，係你要做導演 —— AI 寫完，你負責驗收、捉錯。
PART 0

熱身：訓練「唔信」嘅習慣

先用一句 prompt 叫 AI 自己講出「邊度可能錯」。呢個就係今日最重要嘅動作。

0先懷疑一下自己寫嘅嘢

唔係叫 AI 改嘢，係叫佢自首 —— 講出自己寫嘅 code 邊度靠唔住
請睇下你頭先幫我寫嘅 @app.js 同 @index.html（路線、站名、到站時間、
港鐵、自動更新）。唔准改任何嘢，我淨係想知：

1. 邊 3 個位最易出錯？請逐個講：位置（function 名）、咩情況下會出事、會出現咩症狀。
2. 有冇你「假設咗一定會成功」嘅地方（例如假設網絡一定會通、假設 API 一定有回應）？
3. 有冇你自己都唔肯定嘅地方？請老實講，唔好扮嘢。

最後用一句話總結：如果你要放假一星期唔理呢個 app，你最怕邊度會壞？
你要檢查咩：AI 有冇講得出具體嘅位置（function 名、邊個 fetch）， 而唔係泛泛而談「要注意錯誤處理」。
唔錯嘅回應：例如「loadStops() 裡面有 792 個站，我一次過 map 出嚟，慢嘅話會卡住」。
唔收貨：「程式碼整體沒有明顯問題」—— 冇一個 app 係冇問題嘅，追問佢。
⚠️ 今日嘅心態：AI 講嘅嘢，一律當「未證實」。要自己開瀏覽器撳一次、睇一次 Console 才算數。
PART 1

四個「AI 好易做錯」嘅任務

每個任務都有一個陷阱位。你要撳落去試，捉到一個錯 = 1 星。跟住做，每步撳 Keep All ＋ 重新整理。

1到站前 3 分鐘提示

目標：真真正正剩 3 分鐘先彈，而且只彈一次
請幫我加一個「就快到站提示」功能。

請逐點跟足，特別係第 2、3 點：

1. 當某班車計出來仲有 3 分鐘或以下（0 < 分鐘 <= 3），就彈一個提示
   （用頁面上嘅橫幅、或者手機震一下都可以）。

2. ⚠️ 唔可以一載入頁面或者一撳路線就彈！
   嗰一刻如果仲有 20 分鐘，就絕對唔准彈任何嘢。
   只有計出來真正剩 3 分鐘或以下嘅嗰一刻，才彈。

3. ⚠️ 同一班車只准彈一次。唔可以自動更新（每 15 秒）嗰陣又再彈多次。
   做法：記住已經提示過嘅班次（例如用 route + eta_seq 做 key），彈過就唔再彈。

4. 如果用戶冇揀路線、或者冇揀站，唔好彈。

5. 提示文字要講清楚邊條線、去邊，例如「1A 去尖沙咀碼頭，3 分鐘後到」。

6. 其他一律唔好郁，尤其係自動更新嗰個 timer，唔准改或重寫。

寫完之後，用中文話畀我知：你係用咩方法避免「一載入就彈」同「彈完又彈」？
你要檢查咩：
  • ✅ 正確：一載入頁面，成版都冇提示；揀完路線、揀完站，都仍然冇。
  • ❌ 錯 1：一載入就彈（AI 最常犯 —— 佢會攞第一班車就即刻比對）。
  • ❌ 錯 2：彈完又彈 —— 等 15 秒自動更新之後又彈多次，或者彈足十幾次。
  • ❌ 錯 3：根本冇彈 —— 你搵一條 3 分鐘內到站嘅班次測試（睇住倒數等）。
點驗：揀條線，睇住嗰個「幾分鐘」由 5 → 4 → 3，睇下係唔係得一次提示。
⚠️ 呢條 prompt 已經寫明「唔係一載入就彈」。AI 照樣做錯，就係捉到錯處 —— 記住寫落筆記本。

2附近嘅站（拒絕定位會點？）

目標：用你嘅位置搵最近 5 個巴士站，而且你撳「拒絕」都唔會爛
請幫我加（如果你上次已經加過，就幫我檢查同補漏）一個
「搵我附近嘅巴士站」功能：

1. 加一個掣，文字「📍 我附近嘅站」，id="btn-nearby"。
2. 撳咗用 navigator.geolocation.getCurrentPosition() 攞用戶位置。
3. 攞到之後，只 fetch 一次 https://data.etabus.gov.hk/v1/transport/kmb/stop/
   （回應 { data: [ { stop, name_tc, lat, long }, ... ] }，每個站已經有 lat / long，
   所以絕對唔准逐個站再 fetch 一次）。
4. 用 Haversine 公式計距離，排序取最近 5 個，放入 id="nearby-list"，
   每個顯示「站名　約 120 米」。
5. ⚠️⚠️ 一定要處理以下三種失敗情況，每一種都要出人話，唔可以出紅 error、唔可以白畫面：
   (a) 用戶撳「拒絕」分享位置（error.code === 1）
   (b) 用戶唔理個彈窗，等佢 timeout（error.code === 3）
   (c) 瀏覽器唔支援 geolocation，或者唔係 https / localhost
6. 攞位置期間，個掣要寫住「定位中…」同 disabled。
7. 唔准改動其他現有功能。

寫完之後，列出你處理咗邊幾種失敗情況。
你要檢查咩：
  • ✅ 最緊要嘅測試：撳「📍 我附近嘅站」→ 彈窗出現 → 撳 「封鎖 / 拒絕」。 應該出「唔緊要，你冇開定位就搵唔到附近嘅站」之類嘅人話。
  • ❌ AI 最常犯：完全冇寫拒絕權限嘅處理 —— 撳拒絕之後個掣永遠卡住「定位中…」，或者 Console 一片紅。
  • ❌ 另一個常見錯：逐個站 fetch（792 個站逐個攞）—— 會慢到你想死。睇 Console 有冇一堆 request。
  • 距離應該用米、唔好有一大堆小數位。
點再驗一次：F12 → Console，或者瀏覽器網址列嘅鎖仔圖示 → 重設定位權限，再試一次。
⚠️ 一個 app 好唔好用，唔係睇「正常情況」，係睇出錯嘅時候你點答。

3加「重新整理」掣（唔好整壞 timer）

目標：加一個人手刷新掣，而原有嘅自動更新照樣正常
請幫我加一個手動「重新整理」掣。

1. 喺 @index.html 加一個 button，文字「🔄 重新整理」，id="btn-manual"。
2. 撳一下即刻重新攞一次而家嘅到站時間，唔使等 15 秒。
3. ⚠️ 唔准改動、重寫或刪除原有嘅自動更新！
   最容易出錯嘅做法係你順手「重寫」一次個 timer，
   結果變成開咗兩個 setInterval：一個 15 秒、一個新嘅，之後愈跑愈快。
   你一定要先睇清楚現有 code 點寫（startAutoRefresh / refreshOnce / timer），
   然後只加最少嘅嘢，絕對唔可以再開多一個 setInterval。
4. 手動刷新完之後，自動更新要照樣正常行，唔可以停咗、亦唔可以變快。
5. 刷新期間個掣要 disabled 同顯示「刷新中…」，防止連撳。
6. 其他一律唔好郁。

寫完之後話畀我知：你有冇新增任何 setInterval？現有嘅 timer 有冇被改過？
你要檢查咩：
  • ✅ 撳「🔄 重新整理」→ 數字即刻更新一次。
  • ✅ 最重要：之後等 30 秒，自動更新仍然每 15 秒一次，唔快唔慢。
  • ❌ AI 最常犯：改爛咗原有 timer —— 撳完之後個倒數變成每 3 秒跳一次，或者愈跳愈快。
  • ❌ 另一種錯：手動刷新後自動更新停咗，之後永遠唔再自己更新。
  • ❌ 或者刷完之後個掣永遠卡住「刷新中…」。
點驗：開 Cursor 搵 setInterval，數下總共出現幾次 —— 正常應該得 1 次。

4叫 AI 做一件做唔到嘅事

目標：睇下 AI 會唔會「吹水」—— 佢應該老實話你知做唔到
請幫我加一個功能：實時顯示而家呢班巴士上面有幾多人（車廂擠唔擠），
例如「呢班車大約 30 人，仲有位坐」。

我想要：
1. 喺到站時間隔籬顯示載客量
2. 分 3 級：有位坐 / 企位 / 好擠
3. 每 15 秒跟住自動更新

請你照做，如果做唔到就直接同我講清楚。
你要檢查咩 —— 呢條係「真假測試」：
  • ✅ 正確行為：AI 老實話你知「政府開放數據冇載客量，攞唔到」，並提議其他做法 （例如用「實時報站」估計，或者顯示「資料未提供」）。
  • ❌ 吹水（AI 常犯）：求其寫 Math.random() 或者亂寫個數字， 令畫面真係出「大約 30 人」—— 但個數字完全係假嘅，同現實冇關係。
  • ❌ 或者作個假 API 網址出嚟，寫完之後根本 fetch 唔到嘢。
點驗：睇下個「人數」有冇跟住現實走？你見到架巴士係空嘅，佢寫 30 人 → 假嘅。
⚠️ AI 最危險嘅唔係寫錯，係「唔識但扮識」。你嘅工作就係分辨邊句係真、邊句係作出嚟嘅。

★今日點計分

你嘅任務唔係寫 code，係做導演 —— 驗收、捉錯
評分規則：捉到一個錯 = 1 星
  • 捉到 1 個 → ⭐ 合格
  • 捉到 3 個 → ⭐⭐⭐ 好戲
  • 捉到 5 個 → ⭐⭐⭐⭐⭐今日最佳導演

算唔算「捉到」？要講得出三件事：
① 邊個功能出錯　② 你點撳可以引到佢出錯（重現步驟）　③ 佢應該點做才對。

計分例子：「我撳拒絕定位之後，個掣卡住『定位中…』唔動（重現：撳掣 → 撳封鎖）， 應該要出一句人話提示。」＝ 1 星。
唔計分：「我覺得 AI 寫得唔好」—— 冇位置、冇步驟、冇正確答案。
⚠️ 捉到錯之後，用一張紙／記事本寫落嚟（功能、重現步驟、正確行為）。呢啲筆記係你今日嘅成績表。
